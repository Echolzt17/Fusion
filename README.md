## Fusion 能做什么？

Fusion 是面向 Windows 本机 Codex 桌面客户端的账号池工具。添加自有或经授权使用的账号后，可以统一查看额度、选择新会话的首选账号、排队处理并发请求，并了解本机用量。日常对话仍在 Codex 桌面里完成。

| 需要 | Fusion 提供的能力 |
| --- | --- |
| 管理多个账号 | 浏览器授权、套餐与额度展示、暂停/恢复、重新授权；当前首选卡片持续突出 |
| 按需求选择账号 | 自动、高订阅优先、低订阅优先、高额度优先、低额度优先五种策略 |
| 同时处理多个任务 | 每账号默认 4 个并发名额；繁忙时排队，未绑定的新请求可选择可用备用账号 |
| 保持多轮上下文 | 会话、响应引用、图片引用和加密上下文保持原账号 |
| 查看消耗和运行情况 | 本机累计 Token、近 7 天趋势、今日每小时使用时长、池内请求记录和 Codex 内胶囊概览 |
| 方便开启和退出 | 一键启动；关闭时恢复启用前的接入，等待在途请求并完整退出 Codex |

每个账号仍受自身套餐、模型权限、额度和上游服务状态限制。Fusion 不合并订阅额度，也不提高单账号限额。每台电脑独立运行、独立授权。Codex、候选版 Claude 订阅池与手动 API 来源分别管理，没有跨厂商混合订阅池、API Key 自动池化或跨电脑账号同步。

## v1.0.11 的改进

- **统一工作区入口。** 胶囊按钮融合 Poppins 字体、三箭头悬停和发光滑块下拉，在 Codex / Claude Code / API 间切换查看。
- **账单式多订阅管理。** 可保存多个代理订阅，分别更新和移除，明确选用一个；新增不会覆盖或切走当前订阅，地区/排序等低频操作收进高级设置。
- **切换与停止更可靠。** 选用订阅前等待旧请求读取完成，失败保留原订阅；阻止失效的内核启动任务在关闭或切换后复活。

以下能力沿用此前版本：

- **订阅价格与充值渠道。** 一张卡按软件和套餐查看地区订阅价格，默认 Codex / ChatGPT，每日首次打开更新；另有 PriceAI 渠道比价入口。
- **更集中的操作。** 移除首页常驻说明和设置页重复入口，首页保留一键启停。GitHub 公开更新下载遇到临时故障时有限重试，仍先验签再安装。
- **独立客户端与 API 来源。** Codex 保留订阅账号池并支持手动 Responses API 来源，Claude Code 支持 Messages API 来源；密钥存在当前 Windows 凭据管理器，选择视图不会自动启用。
- **账号池专用网络。** 可保存多个 Clash/Mihomo 订阅，每次选用一个，选择地区与备用顺序，使用固定版本独立内核；仅影响原 Codex 订阅池，不更改系统代理、DNS、TUN 或 API 来源设置。
- **新聊天可读交接与挂件修复候选。** 通过明确的准备、创建、发送操作续接可读任务信息，旧账号密文和上下文引用不跨账号搬运；挂件补充握手、去重和失联恢复。

收到 429、已经发送或输出、工具调用及执行状态不明的业务请求不自动重放。当前更新重试仅用于匿名公开更新下载，不扩大业务请求重试。

## 安装与使用

1. 下载 [Releases 中的安装包](https://github.com/Echolzt17/Fusion/releases)。Windows 10 / 11 x64 使用同一个安装包，包含 WebView2 离线依赖；登录和请求仍需联网。
2. 保持 Codex 桌面自身已登录，并准备可用的显式代理。在 Fusion 中点击“添加账号”，通过浏览器完成授权。Fusion 授权与 Codex 自身登录分别维护。
3. 完成当前任务并保存未发送输入，点击“启动账号池”。软件检查客户端并配置接入，已有客户端完整退出后再打开，未运行时打开一次；随后新建聊天使用账号池。
4. 点击“关闭账号池”或从托盘退出时，软件恢复原接入、排空池内请求并完整退出 Codex，完成后保持 Codex 关闭。关闭主窗口仅隐藏到托盘，账号池继续运行。

**切回官方接入后，池内旧聊天不能直接改用官方账号续接。** 要继续原池聊天，请重新启动账号池；要使用官方账号，请在官方接入下手动打开 Codex，新建聊天并带入必要的任务摘要。Fusion 不迁移加密上下文。

顶部更新按钮只检查并展示说明，点击“立即更新”才下载。下载与修复材料准备期间可稍后更新；安全安装收尾开始后等待完成。账号池已关闭且已脱离时，Fusion 更新不关闭或重启独立运行的 Codex；账号池开启时先完成正常关闭，更新后保持关闭，需点击“启动账号池”才打开客户端。手动覆盖安装前，先正常关闭账号池并退出 Fusion。

代理订阅目录升级为版本 2，旧单订阅会保留。使用新版保存后，旧版会按向前保护拒绝读取新版网络目录，请继续使用新版；这不等于账号数据库 schema 发生迁移。真实 API 旧聊天续接及用量等仍需验收，切换 API 来源请新建聊天。

## 数据与安全边界

请求路径为 **Codex 桌面 → 本机 Fusion 网关 → 原账号的上游服务**。网关默认仅监听 `127.0.0.1:18765`，使用独立本机密钥鉴权。外部 AI 请求使用当前可识别的显式代理，未取得有效代理时明确报错；AI 请求不经过 Fusion 错误报告接收服务器。

账号令牌保存在当前 Windows 用户的凭据管理器；Fusion 不读取、复制或替换 Codex / Cockpit 的登录文件。SQLite 保存账号元数据、设置、数值统计和哈希绑定，不保存对话正文、提示词、图片或完整响应。可读交接正文仅在有界内存和用户明确创建的新原生聊天中存在；专用代理订阅信息加密保存，运行时配置仅在受限的临时目录解密。Codex 用户配置中包含本机网关密钥，请勿分享该 provider 定义。

诊断默认在本机。用户预览确认后才可上报白名单失败诊断与统计，也可仅上报数值摘要。新增挂件计数不包含坐标、窗口句柄、键盘内容或对话正文；桥接成功仅表示 Tauri 接受事件，不能证明前端已执行操作。
