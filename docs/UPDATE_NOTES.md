# Fusion 1.0.12

## 本次重点

- Claude Code 增加独立多订阅账号池，采用与 Codex 一致的启动卡、用量卡和账号卡组，支持浏览器授权、额度刷新、首选切换及已知 Token 统计；两个厂商不混池，原生模型选择保留。
- 移除首页手动聊天续接选择块；普通原账号聊天沿用已有绑定，不需要在 Fusion 再选择。
- 顶部 Codex / Claude Code / API 工作区胶囊整体缩小约三分之一，使文字、箭头和按钮比例协调。
- 修复导入代理订阅期间同步状态查询等待内核锁而阻塞界面的问题；订阅解析移到后台，弹窗显示进度并可在后台继续。
- 节点测速入口常驻可见，未启用专用出口也能测试延迟；显示检测进度，支持停止，临时内核检查后正常关闭。
- Codex 从与本账号身份匹配的授权信息保留 Free 等真实套餐；额度查询失败不再丢失已知套餐，未知额度不当作零。

## 升级与验证范围

本版按维护者明确要求正式发布。上一候选的自动回归为核心235项、桌面82项、界面99项通过，另有11项忽略；正式包的版本、构建、签名与安装保护独立核对。真实 Claude 登录、套餐/额度、多轮工具与签名、用户订阅、覆盖/在线升级及其他原有未完成项目继续待验收，正式发布不等于这些场景全部通过。

Claude 真实启用需要已安装原生 claude.exe，并在 Fusion 中独立授权；不会复制其他工具或原客户端的登录文件。首选只影响新会话，已有会话、工具结果和完整签名保持原账号。账号不可用或请求结果不明时不自动换号或重放。

没有新增 SQLite schema 迁移。原专用网络目录的向前版本检查继续保持，不通过清除数据实现降级。

应用内更新由既有流程恢复接入、等待在途请求并完成关闭。账号池已关闭且脱离时不关闭独立运行的 Codex；更新后保持账号池关闭，仅在点击“启动账号池”时打开。手动安装前请正常关闭账号池并退出 Fusion。
