# Fusion 1.0.11

## 本次重点

- 左上统一为 Codex / Claude Code / API 胶囊入口，采用 Poppins 字体、三箭头悬停动画，点击展开带发光滑块的工作区选择面板。
- 代理与节点改成账单式单卡，常用操作集中，地区、备用顺序、固定及排除等高级设置按需展开。
- 可保存多个独立代理订阅，分别更新和移除，每次明确选用一个；添加不会覆盖或切走当前订阅，不跨订阅自动备用。
- 切换订阅先等待在途请求完成，失败保留原订阅；修复失效内核启动任务在停止或订阅切换后继续启动的问题。
- 开发源码、构建配置、字体与许可同步到 GitHub，供其他 Windows 电脑继续开发；账号、运行数据和发布签名材料仍在各电脑独立保管。

## 升级与验证范围

本版按维护者明确要求发布。自动化检查与真实账号、代理订阅、Win10/Win11、安装/在线升级及持续交互验收分别记录；未完成项目仍待验收。API 来源切换请使用新聊天，既有文字历史的来源绑定和部分用量归因仍有待继续验证与改进。

原单订阅会保留并进入新版多订阅目录。新版写入目录版本 2 后，旧版会按向前保护拒绝读取，不能把降级重装当作读取新版目录的方式；没有新增 SQLite schema 迁移。

更新前请正常关闭账号池并退出 Fusion；通过应用内更新时由原生命周期流程完成安全收尾。已脱离账号池时更新不关闭或重启 Codex，更新后账号池保持关闭，仅点击“启动账号池”时打开。执行状态不明、已输出或已返回工具调用的业务请求仍不自动重放。
