# Fusion 1.0.14-rc.1

## 候选版改动

- 日志上报在内部记住服务器已确认的请求，后续仅发送新增错误和变化后的完整小时统计；相同故障发生在新请求上仍会提交。用户确认后自动核对旧安装已提交记录，预览阶段不联网。没有新增内容时关闭确认卡片，不生成重复报告或新回执。
- 收到回执后原子保存回执及去重记录；断网、回执丢失、写盘或清理失败继续原编号/原字节。损坏及未来版本不清空重传。仍由用户手动确认上报，不增加后台上传。
- 兼容报告服务新增受限核对接口和新增错误即时事件，独立 VPN 检查每3小时运行，保留已有进度，失败不误确认，无新增且健康无变化静默。
- 额度胶囊显示账号池最近实际请求账号和套餐；尚无业务请求标记首选账号。展开可看短长周期、快照时间及原生登录套餐说明，合计额度口径明确，失效额度显示未知。

## 验证与使用边界

本版是本地候选，不包含 GitHub 正式发布或自动替换日常客户端。核心、报告协议/服务、桌面增量上报和相关界面已完成隔离检查；真实账号、Windows桌面和覆盖安装仍待验收。先部署兼容报告服务再进行候选上报；部署是否完成请以维护记录为准。原有客户端、接入恢复、账号绑定与不自动重放规则保持。

# Fusion 1.0.13

## 本次重点

- Codex 接入显示模型厂商 OpenAI，同时保留独立账号池路由和个人登录识别。显示名称不表示已切为官方直连；实际启停状态仍在 Fusion 显示。关闭账号池恢复原接入，旧池聊天不会自动改走另一官方账号。
- 修复同一本地聊天在账号额度耗尽后无法继续的问题：完整可读历史的新用户轮次可在后台选择备用账号；明确 HTTP 429 拒绝可有界换号。已有输出、工具调用或执行结果不明的请求不会自动重放。
- 后续长聊天使用可读本地压缩摘要。实际桌面内核已验证，同一聊天在 A 账号压缩后，A 额度耗尽仍可携带摘要继续使用 B 账号。既有只剩压缩密文、未知账号密文、服务端或图片引用及未完成工具链仍保持原归属，不能直接换号。
- 连接设置新增本机项目目录恢复与原本机历史聊天入口，帮助找回原生退出登录、换个人账号后隐藏的本机视图。项目文件仍在本地；入口不会复制账号数据、新建续接聊天或自动发送消息。
- 为具有稳定聊天和轮次身份的业务增加持久哈希防重放；排队或授权阶段明确未发送的取消会释放预占，执行不明或已开始输出的请求保持保护。
- 修复当前 Codex 内核默认压缩请求与本机 JSON 网关不兼容的问题；启动时管理压缩开关，关闭时恢复原值，并保留外部配置修改的冲突保护。

## 升级与验证范围

本版按用户明确要求作为正式版发布。最终自动检查为核心 263 项、桌面 88 项、界面 103 项通过；忽略项目不计入通过。构建、版本、签名及安装保护另行核对。实际 0.167 桌面内核在临时 HOME、公开假登录和本机假服务中验证了同聊天 A→B、可读压缩后 A→B、原生图片生成/修改/保存及失败不重放；关闭后旧池聊天被原生 provider 检查拒绝，官方业务请求为零。

上述内核隔离验证不等于真实订阅和桌面验收。真实额度耗尽、桌面菜单显示、换登录后的目录恢复与原聊天续发、覆盖安装及在线升级继续待验收。正式发布不会把这些项目改记为通过。

Claude Code 独立订阅池、手动 API 来源和代理功能保留原有语义；此次 Codex 后台换号修复不改变 Claude 的会话绑定，不增加跨厂商迁移或账号同步。没有新增 SQLite schema 迁移。

应用内更新沿用接入恢复、等待在途请求与正常关闭流程。账号池已关闭且脱离时，不关闭独立运行的 Codex；更新后账号池保持关闭，仅点击“启动账号池”才打开。手动安装前请正常关闭账号池并退出 Fusion。
