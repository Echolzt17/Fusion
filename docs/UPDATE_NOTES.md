# Fusion 1.0.10

## 本次重点

- 设置页新增 AI 订阅价格对比，每日首次打开时更新，默认 Codex / ChatGPT，可切换软件、套餐和查看地区价格；另有 PriceAI 充值渠道入口。
- 移除首页常驻说明和设置页重复的 Codex 接入卡，账号池统一在首页启动和关闭。
- GitHub 更新遇到临时连接、读取或部分服务错误时有限自动重试，保留取消、签名和安装前检查。
- 增加 Codex / Claude Code 独立工作区及手动 API 来源，密钥由 Windows 凭据管理器保存；仅明确启用才改变接入。
- 设置页增加账号池专用代理与节点管理，使用固定版本内核，仅影响原 Codex 订阅池，不更改系统代理、DNS 或 TUN。
- 增加可读聊天交接，准备、创建、发送及打开分别操作，不搬运旧账号密文；挂件增加状态握手、去重和失联恢复。

## 升级与验证范围

本版按维护者明确要求发布。自动化检查与真实账号、Win10/Win11、在线升级和持续交互验收分别记录；未完成项目仍待验收，不承诺所有网络或挂件问题已解决。

账号池关闭且接入已脱离时，更新不关闭或重启 Codex；使用中先完成正常关闭，更新后账号池保持关闭，仅点击“启动账号池”时打开。已发送、已输出、工具调用或执行状态不明的业务请求仍不自动重放。
