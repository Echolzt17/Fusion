## 本次重点

- 修复 Codex 同一聊天在原账号明确返回 HTTP 429 后，因冷却解除或备用授权失败而回选原账号的问题。完整可读的新用户轮次会尝试可用的备用账号。

- 减少大上下文的重复复制，修正备用账号接续后的传输统计。

- 账号专属图片、服务端引用、未知密文和未完成工具链保持原账号归属。执行状态不明或已有输出的请求继续受防重放保护。
- 三种额度切换场景已用实际 Codex 内核和本机测试上游验证。真实账号额度耗尽及桌面在线升级仍待验收。
