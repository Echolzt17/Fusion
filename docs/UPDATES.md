# Fusion 稳定版发布与安全更新

固定仓库为 https://github.com/Echolzt17/Fusion。从 1.0.9 起公开经过审查的开发源码快照，沿用既有公开历史，不上传维护机私有 Git 历史。本轮版本为 1.0.13；源码提交和签名安装包/更新清单是独立步骤，只有包公开可下载、字节核对成功并推进清单后，已安装客户端才能发现新版。

## 使用者

启动与每六小时检查只查询清单，不自动下载。顶部检查展示说明，选择立即更新才下载与验证；进入安全安装收尾前可稍后更新。账号池已关闭且已脱离时不关闭或重启独立 Codex；账号池开启时先正常恢复原接入、排空并退出客户端。更新后保持账号池和 Codex 关闭，只有点击启动账号池才打开。

检查、下载或验签失败保留旧版本，不冒充更新成功。升级保留本机数据，不同步账号。1.0.13 的本机项目恢复和历史打开是手动操作，不由启动、更新或正常关闭自动执行；旧池聊天不能在恢复官方接入后直接改走官方账号。

## 维护者

1. 同步 npm/Cargo/Tauri 版本、更新说明和公开源码，保留精确锁文件、资源、测试与许可；业务文件必须等于审查后的本地源码。
2. npm run updates:release -- prepare 准备检查、签名包、manifest 和实际验收记录，不安装软件。未完成真实验收保持 pending，具体版本的明确发布授权不能当作实机通过。
3. 使用项目外受保护的原签名材料和仓库写入授权，不输出或提交私钥、密码、令牌或 DPAPI 文件；新维护机见 DEVELOPMENT.md。
4. 发布前核对包签名、版本、源码清单和固定仓库身份；不覆盖已有版本附件。源码新提交以当前远端公开 head 为唯一父，不能推本机私有历史。
5. 公开下载字节核对后先推进 preview.json，最后推进 stable.json；保持默认验收规则与原更新公钥。

正式端点为 https://raw.githubusercontent.com/Echolzt17/Fusion/main/updates/stable.json。更新签名不是 Windows Authenticode 证书，不能靠生成替代密钥或关闭验签绕过缺失材料。
