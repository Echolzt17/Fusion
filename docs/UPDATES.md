# Fusion 稳定版发布与安全更新

固定仓库为 https://github.com/Echolzt17/Fusion。从 1.0.10 起提供当前开发源码快照、签名安装包和公开说明；普通源码提交不触发客户端更新。只有签名包公开可下载、字节核对成功且更新清单推进后，客户端才发现新版。

## 使用者

启动与每六小时的检查只查询清单，不自动下载。顶部检查后展示说明，用户选择立即更新才下载和验证包。进入安全安装阶段前可稍后更新；进入安全收尾后等待完成。账号池已关闭且已脱离时不关闭或重启独立 Codex；账号池开启时先恢复原接入、排空并退出客户端。安装后保持账号池关闭，仅点击启动账号池时打开 Codex。

检查/下载失败保留旧版本；真实故障不冒充更新成功。升级保留本机数据，但不迁移账号到其他电脑。

## 维护者

1. 同步 npm/Cargo/Tauri 版本和 docs/UPDATE_NOTES.md；首行须匹配版本，包含本次重点。
2. npm run updates:release -- prepare 执行检查、测试、签名构建及安装保护，准备 EXE、SIG、manifest 和实际验收文件；不上传或安装。
3. 实际验收独立记录，未完成保持 pending；默认正式发布检查保持，不伪填验收。版本专属的维护者明确发布授权须绑定具体源码与包，不能被当作真实验收通过。
4. 发布只使用既有项目外的原签名材料和独立仓库授权，不输出或提交私钥、密码、令牌或 DPAPI 文件。公开快照不含这些材料；新维护机见 DEVELOPMENT.md。
5. 包签名、版本及公开下载字节核对后，再更新旧客户端兼容的 preview.json，最后更新 stable.json。两者指向同一稳定版本，不覆盖已有版本附件。

正式端点固定为 https://raw.githubusercontent.com/Echolzt17/Fusion/main/updates/stable.json。更新公钥保持原值。签名不是 Windows Authenticode 证书；缺少原密钥不能靠生成替代密钥绕过。
