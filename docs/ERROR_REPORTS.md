# 错误报告与脱敏诊断

Fusion 默认不自动上传业务请求或错误。主窗口可手动准备、预览和提交白名单失败诊断，也可只提交数值统计摘要。报告不含请求/响应正文、授权头、回调代码、刷新令牌、账号邮箱或原始聊天标识；失败保留原报告编号，避免重复统计。

本机诊断只包含有限错误分类、版本、时间、数值和挂件输入链路计数。widgetInput 不含坐标、窗口句柄、键盘或正文，桥接成功不等于 WebView 已执行操作。1.0.13 的业务防重放仅保存稳定聊天/轮次与请求的持久哈希状态，不记录正文；本机项目记忆仅保存本地目录、标题和顺序，不复制原生账号 atoms 或聊天。

crates/report-protocol 与 crates/report-server 提供接收协议和服务实现。deploy/reports 是示例部署模板，reports.example.com 必须替换成自己控制的主机和证书；scripts/configure-report-monitor.ps1 与 read-report-events.ps1 的公开副本使用相同示例地址。实际管理授权在部署环境独立配置，不能从源码取得；应用内既有公开报告端点保持。

测试只使用临时数据库、公开假凭据与假服务，不读取真实访问材料。自动化、实际内核隔离检查和真实客户端验收分别记录；不要向公开仓库提交原始配置、网络日志、运行数据库或诊断全文。普通开发与提交边界见 DEVELOPMENT.md。
