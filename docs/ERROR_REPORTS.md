# 错误报告与脱敏诊断

Fusion默认不自动上传。主窗口可准备、预览、确认提交白名单失败诊断或数值摘要，不包含请求/响应正文、授权头、回调代码、刷新令牌、邮箱、原始聊天标识、图片、工具参数、路径或节点地址。

1.0.14-rc.1在内部保存服务器确认过的请求与小时统计指纹；预览排除本机已确认项目，确认后才以受限POST /v1/error-reports/known核对同安装的候选编号和指纹。服务器只返回候选子集，不提供枚举/原报告读取。核对失败不静默重传全量，全部已知不生成新报告或回执；同类新请求仍会提交，统计仅发送变化的完整桶。

回执和确认集合同次原子保存后再清理pending。接收状态不明、回执丢失或写盘失败保留原编号/原字节；重启不重新过滤已派发报告。确认已保存但清理失败只本地收尾。损坏/未来版本/安装标识丢失保持原文件并报错，摘要模式不误确认未发送错误。内部去重清单不在界面展示。

报告协议/服务保留v1/v2/v3和原回执。真正新增错误写即时事件，首次升级补发旧日报/early尚未覆盖样本；旧通知保持兼容，由维护脚本按上线边界抑制重复。read-report-events.ps1使用持久待处理批次，整理成功后按AcknowledgeBatch确认，失败不推进。独立维护检查每3小时运行，无新增/健康变化不重复提醒；此检查不会替客户端自动上传。

crates/report-protocol与crates/report-server提供严格白名单接收实现。deploy/reports和公开监控脚本使用reports.example.com示例主机，需要替换为自己控制的地址/证书并独立配置管理授权；实际管理员凭证不在源码、客户端或安装包。应用中既有公开报告端点保持。

本机诊断只含有限分类、版本、时间、数值及挂件链路计数。widgetInput不含坐标、窗口句柄、键盘或正文；桥接成功不等于WebView完成动作。业务防重放保存持久哈希，不保存正文或真实身份。本机项目记忆只包含目录、标题和顺序，不复制原生账号数据。

测试使用临时数据库、公开假凭据和假服务；生产部署不插入假错误。真实用户增量上报、旧安装实际样本和完整桌面交互继续待验收，见ACCEPTANCE。不要提交原始配置、网络日志、运行数据库或诊断全文。
