# 错误报告与脱敏诊断

Fusion默认不自动上传。主窗口可准备、预览、确认提交白名单失败诊断或数值摘要，不包含请求/响应正文、授权头、回调代码、刷新令牌、邮箱、原始聊天标识、图片、工具参数、路径或节点地址。

1.0.14保留候选版的内部增量上报记录：预览排除本机已确认项目，确认后才以受限POST /v1/error-reports/known核对同安装的候选编号及指纹。服务器只返回候选子集，不提供枚举或原报告读取。核对失败不静默重传全量，全部已知不生成新报告或回执；同类新请求仍会提交，统计只发送变化后的完整桶。

回执和确认集合同次原子保存后再清理pending。接收状态不明、回执丢失或写盘失败保留原编号及原字节；重启不重新过滤已派发报告。确认保存后清理失败只本地收尾。损坏、未来版本或安装标识丢失保持原文件并报错，摘要模式不误确认未发送错误。

报告协议/服务保留v1/v2/v3及原回执。新增错误与即时事件同事务保存，首次升级补发旧日报/early未覆盖样本；维护脚本按上线边界避免重复提醒，以持久待处理批次和匹配确认保证失败不推进。独立维护检查每3小时运行，无新增或健康变化时不重复提醒，不替客户端自动上传。

本轮新增的本地routing字段只保存固定枚举原因，例如可读新轮次、已绑定轮次、密文或不支持的历史结构；不保存正文、类型原文、身份或加密材料，也不加入远端报告线格式。业务防重放只保存持久哈希。本机项目记忆只含目录、标题和顺序，不复制原生账号数据。

crates/report-protocol与crates/report-server提供严格白名单接收实现。deploy/reports及公开监控脚本使用reports.example.com示例地址，需要自行配置受控主机、证书及独立管理授权；实际管理员凭证不在源码、客户端或安装包。测试使用临时数据库、公开假凭据及假服务；真实增量上报和完整桌面交互继续待验收，不提交原始配置、网络日志、运行数据库或诊断全文。
