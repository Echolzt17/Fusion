# 错误报告与脱敏诊断

Fusion 默认不自动上传业务请求或错误。主窗口可手动准备、预览和提交白名单错误报告，也可选择仅提交统计摘要。报告不包含请求/响应正文、授权头、回调代码、刷新令牌、账号邮箱或原始会话标识。失败保留原报告编号，避免重复提交统计；实际服务器部署和客户端验收分别记录。

本机导出诊断包含有限错误分类、版本、时间、数值和当前挂件输入链路计数。widgetInput 只保留当前或最后一个表面的原生接收、前台拒绝、派发、桥接成功/失败和相对时间，没有坐标、窗口句柄、键盘或正文。桥接成功不代表 WebView 收到或按钮完成；挂件 show 与 ready 状态一致性仍属后续验证项。不要把原始配置、网络日志或运行数据库提交到公开仓库。

crates/report-protocol 和 crates/report-server 包含接收协议与服务实现。deploy/reports 是示例部署模板，reports.example.com 必须替换为自己控制的主机和证书路径，不直接用于现有生产服务器。scripts/configure-report-monitor.ps1 与 read-report-events.ps1 的公开副本使用相同示例地址；实际管理授权独立在部署环境配置，不能从源码取得。应用内既有公开报告端点保持。

测试使用临时数据库和公开假凭据，不读取真实报告、访问材料或本机账号。1.0.11 的界面、多订阅和公开发布记录不能被当作所有客户端、统计归因或真实网络问题已解决的证明。普通开发、测试与提交边界见 DEVELOPMENT.md。
