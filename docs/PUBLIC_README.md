## v1.0.13 的改进

- Codex 显示模型厂商 OpenAI，保留个人登录识别及独立账号池路由；账号池的运行状态仍在 Fusion 中明确显示。关闭时恢复原接入，旧池聊天不会误发给官方账号。
- 同一个本地聊天的完整可读新用户轮次，在原账号额度耗尽或不可用时选择备用账号；只有明确 HTTP 429 拒绝可在输出前有界换号。任务已经输出、返回工具调用或执行不明确时不自动重放。
- 后续长聊天使用可读本地压缩摘要，避免新聊天压缩后只剩账号专属密文；既有未知密文、服务端或图片引用及未完成工具链继续保持原账号，不能承诺所有旧聊天均能无损换号。
- 修复当前 Codex 内核默认请求压缩与本机 JSON 网关的兼容问题，并对稳定聊天、轮次身份增加持久哈希防重放；明确尚未派发的取消请求可正常再发。
- 连接与设置新增本机项目目录恢复及原本机历史聊天入口。Codex 退出后换个人登录会切换账号视图，本地文件没有随账号移动；恢复目录不会复制账号状态或迁移聊天。

自动回归：核心 263 项、桌面 88 项、界面 103 项通过，核心 5 项、桌面 7 项默认忽略。已用实际 0.167 内核、临时 HOME、公开假登录和本机假服务验证同聊天 A→B、A→本地压缩摘要→B，以及关闭后不串官方接入；这些不等于真实账号验收。签名构建、版本和安装保护分别核对；真实额度耗尽、原生桌面显示、项目恢复、真实 Claude/代理业务与覆盖安装仍待验收。

## Fusion 能做什么？

Fusion 是面向 Windows 本机 Codex 桌面客户端的账号池工具。添加自有或经授权使用的账号后，可以统一查看额度、选择首选账号、在可安全续接的新用户轮次后台选择备用、排队处理并发请求，并了解本机用量。日常对话仍在 Codex 桌面里完成。

| 需要 | Fusion 提供的能力 |
| --- | --- |
| 管理多个账号 | 浏览器授权、套餐与额度展示、暂停/恢复、重新授权；当前首选卡片持续突出 |
| 按需求选择账号 | 自动、高订阅优先、低订阅优先、高额度优先、低额度优先五种策略 |
| 同时处理多个任务 | 每账号默认 4 个并发名额；健康首选繁忙时等待，不为并发满频繁换号 |
| 延续同一本地聊天 | 完整可读历史的新用户轮次可在原账号不可用时后台换号；密文、服务端和图片引用及未完成工具链保持原归属 |
| 找回本机目录和聊天入口 | 显式恢复本机目录，或在 Codex 打开所选原本机历史；不复制账号状态或创建聊天副本 |
| 查看消耗和运行情况 | 本机累计 Token、近 7 天趋势、今日每小时使用时长、池内请求记录和 Codex 内胶囊概览 |
| 方便开启和退出 | 一键启动；关闭时恢复启用前的接入，等待在途请求并完整退出 Codex |

每个账号仍受自身套餐、模型权限、额度和上游服务状态限制。Fusion 不合并订阅额度，也不提高单账号限额。每台电脑独立运行、独立授权。Codex、Claude 订阅池与手动 API 来源分别管理，没有跨厂商混合订阅池、API Key 自动池化或跨电脑账号同步。

## v1.0.11 的改进

- **统一工作区入口。** 胶囊按钮融合 Poppins 字体、三箭头悬停和发光滑块下拉，在 Codex / Claude Code / API 间切换查看。
- **账单式多订阅管理。** 可保存多个代理订阅，分别更新和移除，明确选用一个；新增不会覆盖或切走当前订阅，地区/排序等低频操作收进高级设置。
- **切换与停止更可靠。** 选用订阅前等待旧请求读取完成，失败保留原订阅；阻止失效的内核启动任务在关闭或切换后复活。

以下能力沿用此前版本：

- **订阅价格与充值渠道。** 一张卡按软件和套餐查看地区订阅价格，默认 Codex / ChatGPT，每日首次打开更新；另有 PriceAI 渠道比价入口。
- **更集中的操作。** 移除首页常驻说明和设置页重复入口，首页保留一键启停。GitHub 公开更新下载遇到临时故障时有限重试，仍先验签再安装。
- **独立客户端与 API 来源。** Codex 保留订阅账号池并支持手动 Responses API 来源，Claude Code 支持 Messages API 来源；密钥存在当前 Windows 凭据管理器，选择视图不会自动启用。
- **账号池专用网络。** 可保存多个 Clash/Mihomo 订阅，每次选用一个，选择地区与备用顺序，使用固定版本独立内核；仅影响原 Codex 订阅池，不更改系统代理、DNS、TUN 或 API 来源设置。
- **新聊天可读交接与挂件修复候选。** 通过明确的准备、创建、发送操作续接可读任务信息，旧账号密文和上下文引用不跨账号搬运；挂件补充握手、去重和失联恢复。

只有完整可读新用户轮次被明确 HTTP 429 拒绝时，才可在输出前有界选择备用。其他已发送请求、输出、工具调用及执行状态不明的业务不自动重放。匿名公开更新下载仍使用独立的有限恢复规则。

## 安装与使用

1. 下载 [Releases 中的安装包](https://github.com/Echolzt17/Fusion/releases)。Windows 10 / 11 x64 使用同一个安装包，包含 WebView2 离线依赖；登录和请求仍需联网。
2. 保持 Codex 桌面自身已登录，并准备可用的显式代理。在 Fusion 中点击“添加账号”，通过浏览器完成授权。Fusion 授权与 Codex 自身登录分别维护。
3. 完成当前任务并保存未发送输入，点击“启动账号池”。软件检查客户端并配置接入，已有客户端完整退出后再打开，未运行时打开一次；随后新建聊天使用账号池。
4. 点击“关闭账号池”或从托盘退出时，软件恢复原接入、排空池内请求并完整退出 Codex，完成后保持 Codex 关闭。关闭主窗口仅隐藏到托盘，账号池继续运行。

**切回官方接入后，池内旧聊天不能直接改用官方账号续接。** 要继续原池聊天，请重新启动账号池；要使用官方账号，请在官方接入下手动打开 Codex，新建聊天并带入必要的任务摘要。Fusion 不迁移加密上下文。

如果在同一台电脑退出 Codex 并登录另一账号后看不到原项目，可在“连接与设置 → 本机项目”刷新目录，确认草稿已保存后恢复目录入口；该动作会切到空白聊天输入页。下方可显式读取本机历史目录并在 Codex 打开原聊天，不会创建副本或发送消息。打开历史不代表其账号专属上下文已经可以跨账号续发。

顶部更新按钮只检查并展示说明，点击“立即更新”才下载。下载与修复材料准备期间可稍后更新；安全安装收尾开始后等待完成。账号池已关闭且已脱离时，Fusion 更新不关闭或重启独立运行的 Codex；账号池开启时先完成正常关闭，更新后保持关闭，需点击“启动账号池”才打开客户端。手动覆盖安装前，先正常关闭账号池并退出 Fusion。

代理订阅目录升级为版本 2，旧单订阅会保留。使用新版保存后，旧版会按向前保护拒绝读取新版网络目录，请继续使用新版；这不等于账号数据库 schema 发生迁移。真实 API 旧聊天续接及用量等仍需验收，切换 API 来源请新建聊天。

## 数据与安全边界

请求路径为 **Codex 桌面 → 本机 Fusion 网关 → 本轮所选账号的上游服务**。网关默认仅监听 `127.0.0.1:18765`，使用独立本机密钥鉴权。外部 AI 请求使用当前可识别的显式代理，未取得有效代理时明确报错；AI 请求不经过 Fusion 错误报告接收服务器。

账号令牌保存在当前 Windows 用户的凭据管理器；Fusion 不读取、复制或替换 Codex / Cockpit 的登录文件。SQLite 保存账号元数据、设置、数值统计和哈希绑定，不保存对话正文、提示词、图片或完整响应。本机项目记忆只保留本地路径、标题和顺序；可读续接投影只在当前请求内存中存在。专用代理订阅信息加密保存，运行时配置仅在受限的临时目录解密。Codex 用户配置中包含本机网关密钥，请勿分享该 provider 定义。

诊断默认在本机。用户预览确认后才可上报白名单失败诊断与统计，也可仅上报数值摘要。新增挂件计数不包含坐标、窗口句柄、键盘内容或对话正文；桥接成功仅表示 Tauri 接受事件，不能证明前端已执行操作。

## 当前验证范围

核心、桌面、界面、更新和安装保护均有自动化检查，相关夹具使用临时路径和假服务。自动化通过不替代真实账号、安装升级或跨电脑验收。

仍待完成的项目包括：新版真实额度耗尽后的同聊天换号、关闭后的原生菜单、换个人登录后的目录/原聊天显示与续发、部分 Win10 / Win11 组合和网络环境的持续使用、Codex 原生生图/保存/连续改图，以及挂件偶发点击或拖动失灵的现场定位。部分环境的 502 / 503、断流根因尚未全部确认。实际结果与待验收项见[维护记录](https://github.com/Echolzt17/Fusion/blob/main/docs/MAINTENANCE.md)和[验收说明](https://github.com/Echolzt17/Fusion/blob/main/docs/ACCEPTANCE.md)。

本仓库从 v1.0.9 起同时提供经过审查的应用源码、构建配置、锁文件、测试、字体与第三方许可说明，方便在其他 Windows 电脑继续开发。公开源码采用当前开发快照，不包含原维护机的私有 Git 历史、账号、运行数据库、诊断材料或发布私钥。

```powershell
git clone https://github.com/Echolzt17/Fusion.git
cd Fusion
npm ci
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/prepare-network-kernel.ps1
npm run check
npm test
npm run web:build
```

桌面开发需要 Rust MSVC 工具链、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。完整环境配置、测试及签名发布边界见[开发指南](https://github.com/Echolzt17/Fusion/blob/main/docs/DEVELOPMENT.md)。普通开发不需要发布私钥；在新电脑使用账号池时需重新登录账号，不通过源码仓库搬运凭据。
