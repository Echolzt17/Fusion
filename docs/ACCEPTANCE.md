# Fusion 1.0.13 验收

安装包、界面、EXE、Cargo/npm 版本均须为 1.0.13。本版按维护者明确授权发布，自动化、实际内核隔离验证与真实客户端验收分别记录；未完成的真实项目保持 pending，不把默认忽略项、公开假登录或模拟 IPC 记为实机通过。

## 本版实际检查

- 核心 263 passed / 5 ignored，桌面 88 passed / 7 ignored，界面 103 passed；类型/工作区检查与 Clippy -D warnings 通过。
- 实际 0.167 内核在临时 HOME 下验证同 thread A→B，以及 A→可读本地压缩摘要→B；旧 A 密文不发送给 B。
- 临时官方接入恢复后，旧池聊天被 modelProviderMismatch 拒绝，官方业务计数为 0；假登录字节和原聊天 ID 保持。
- 签名构建、生产 EXE 离线验签、源码/EXE/安装器版本一致及安装保护 22/30/5 项通过；真实安装、用户配置和注册表写入均未作为通过项。

## 真实 Codex 验收（pending）

- 保持 Codex 原个人登录，启用后显示 OpenAI，Fusion 明确显示账号池启停；关闭恢复原接入，旧池聊天不误发给官方账号。
- 用独立本机项目验证真实额度耗尽后完整可读新用户轮次在同聊天后台换号；明确 429 的有界备用与输出后不重放分别确认。
- 真实长聊天经过本地压缩后继续换号；仅含旧压缩密文、未知引用、图片和未完成工具链仍保持原账号或明确停止，不能记为无损迁移。
- 同机退出原生登录再登录另一账号后，手动恢复本地目录入口；先保存草稿，确认没有自动发送或更改原生账号状态。
- 本机历史目录选择原聊天后在 Codex 打开，确认不创建副本；显示与继续发送分别记录，不将打开成功当作跨账号续发通过。
- 有在途、关闭、更新或账号切换时不得自动打开目录/聊天，关闭成功后 Codex 保持退出。
