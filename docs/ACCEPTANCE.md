# Fusion 1.0.11 验收

安装包、界面、EXE、Cargo/npm 版本均须为 1.0.11。

本版按维护者明确指令准备发布。自动检查与真实验收分别记录，未完成项目保持 pending；不得把临时假服务、模拟 IPC 或默认忽略项记为真实通过。最终构建和发布结果以对应 Release 及维护者最终补记为准。

## 新版界面与多订阅（实机 pending）

- 左上只提供 Codex / Claude Code / API 三项；选择、键盘、点击外部与收起可用，切换视图不改变实际接入。
- 胶囊使用本地 Poppins 600，悬停三箭头、伸展和光晕可见；明暗、窄窗和减少动态效果分别检查，最长 Claude Code 标签不截断或横向溢出。
- 收据式代理卡集中常用操作，高级地区策略、顺序与排除按需展开；界面状态与实际选用订阅一致。
- 多个订阅分别保存、更新和移除；新增不覆盖或自动切换当前项，首次导入不自动启用，不跨订阅自动备用。
- 选用订阅等待旧请求和响应读取完成，失败保留原项；删除未选用项不打断当前连接，删除当前项排空并停止，不自动选择其他项。
- 旧单订阅记录可读取；目录未来版本拒绝覆盖并保留原数据。前向保护及损坏数据试验只在临时路径执行，实机旧版本升级与数据保持仍 pending。
- 退出、禁用和订阅切换后不被已失效的内核启动任务复活；真实内核与在途业务排空另行确认。

## 既有客户端与安装（pending 项继续保留）

- 使用独立测试项目和新聊天，真实登录由使用者完成，不读取或分享 auth.json、凭据或配置全文。
- 启动完成配置、旧进程退出及新客户端核验；关闭恢复原接入、等待池内任务并保持 Codex 关闭。已脱离时 Fusion 更新不操作独立 Codex，更新后不自动启用账号池。
- 原池聊天保持原账号与有效绑定。API 切换使用新聊天；旧纯文字会话来源识别、Responses 失败归因和 Messages 缓存用量的已知后续项不能记为通过。
- 生图、改图、多轮上下文、客户端取消、长任务和可读交接分别验收，不跨账号搬运密文或原引用。
- 挂件持续点击、拖动、跨屏 DPI、连续中文输入及 ready 前原生可见性须真实验证；桥接成功不代表前端已完成动作。
- Win10/Win11、覆盖/在线升级、账号绑定、在途排空及独立恢复尚未完成的组合继续 pending。

故障注入、超时、前向版本与损坏配置试验只用于临时路径和假服务，不断开重要真实任务。自动测试命令见 [开发指南](DEVELOPMENT.md)。
