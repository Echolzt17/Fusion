# Fusion 1.0.15 验收

安装包、界面、EXE、Cargo/npm 版本均须为 1.0.15。发布与真实验收分别记录。

## 自动验证与隔离验证

- 核心回归包括明确 429 后持续排除原账号、备用授权失败、已绑定图片和未知密文归属、建连失败释放占用与响应头丢失保留占用。
- 已在实际 Codex 内核 0.169.0-alpha.11.1 和本地测试上游验证三种同聊天续接。真实账号及日常客户端尚待验收。

## 真实客户端验收（pending）

- 在真实订阅额度耗尽或授权不可用时，确认完整可读新用户轮次在原本地聊天中接到备用账号；明确429、已输出和工具链中的故障分别确认。
- 原用户既有混合密文历史单独验收。未知归属、仅含压缩密文、服务器或图片引用、未完成工具链不能直接跨号；明确409不算该旧聊天已经恢复无损接续。
- 真实本地长聊天压缩、原生生图及多轮改图、关闭后的原接入恢复和原账号归属，分别确认没有跨账号发送专属上下文。
- 增量日志上报、旧安装实际样本核对、失败保持原编号、重启/覆盖升级去重及胶囊业务账号归属。
- Claude独立订阅池、手动API来源、专用代理真实业务、Windows中文输入、挂件连续交互、Win10/Win11安装保留账号与设置。
- 独立更新、在途排空、恢复官方接入、修复材料及原始旧版的实际GitHub在线升级。公开包可下载不代替这些验收。

所有故障注入仅使用临时路径、公开假凭据与本机假服务，不断开或操作重要真实任务。发布授权与acceptance.json中的实际结果分别保存，pending项目保持pending。
