# Fusion 1.0.10 验收

安装包、界面、EXE、Cargo/npm 版本均须为 1.0.10。

本版按维护者明确指令发布；自动检查与真实验收分别记录。真实 Windows 10/11、覆盖/在线升级、账号绑定、在途排空、独立恢复、四会话和团队网络验收未完成的项目保持 pending，不得把假服务或浏览器测试记成真实通过。

- 使用独立测试项目和新聊天；真实登录由使用者完成，不读取/分享 auth.json、凭据或配置全文。
- 启动须完成配置、旧进程退出及新客户端核验；关闭恢复原接入、等待池内任务完成并使 Codex 保持关闭。已脱离时 Fusion 更新不操作独立 Codex，更新后不自动启用账号池。
- 原池聊天仅由原账号和有效绑定续接；官方接入使用新聊天和明确的可读任务交接，不跨账号搬运密文或原引用。
- 慢额度刷新不阻塞其他操作；全部刷新汇总成功及失败，失败保留旧数据。移除账号前提示旧绑定不能恢复，取消不删除。
- 短期冷却只在发送前等待，保持原账号且可取消；暂停、需重新授权、删除、额度耗尽或长冷却及时拒绝。已发送、429、工具调用或执行不明均不自动重放。
- 生图、改图、多轮上下文、客户端取消及持续使用分别确认；正常启动关闭仍为一键，救援须独立预览确认。
- 挂件点击、拖动、跨屏 DPI 和连续中文输入须真实验证；诊断桥接成功不代表前端已执行。

故障注入、超时和损坏配置仅用于临时路径及假服务；不要断开重要真实任务来验收。自动测试命令见 [开发指南](DEVELOPMENT.md)。
